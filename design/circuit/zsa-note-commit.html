SinsemillaHashToPoint evaluations

To evaluate our OrchardZSA NoteCommit, we must evalute h={hZEC​hZSA​​ if AssetBase=VOrchard otherwise​.

We observe that the messages to hash in hZEC​ and hZSA​ have a similar prefix {hZEC​=SinsemillaHashToPoint("z.cash:Orchard-NoteCommit-M",prefix∣∣suffixZEC​)hZSA​=SinsemillaHashToPoint("z.cash:ZSA-NoteCommit-M",prefix∣∣suffixZSA​)​ where ⎩⎨⎧​prefix=a∣∣b∣∣c∣∣d∣∣e∣∣f∣∣gsuffixZEC​=h0​∣∣h1​∣∣0000suffixZSA​=h0​∣∣h1​∣∣h2ZSA​∣∣i∣∣j​

We will optimize the circuit by leveraging the fact that their respective messages share a common prefix. More precisely, the circuit will contain the following steps:

  1. Evaluate Qinit​ the initial state of the hash function thanks to a multiplexer gate Qinit​=MUX(QZSA​,QZEC​,AssetBase==VOrchard) where {QZEC​=Q("z.cash:Orchard-NoteCommit-M")QZSA​=Q("z.cash:ZSA-NoteCommit-M")​
  2. Evaluate hcommon​ which is equal to the Sinsemilla hash evaluation from the inital point Qinit​ with the message prefix hcommon​=SinsemillaHash(Qinit​,prefix)
  3. Evaluate hZSA​ and hZEC​ which are equal to the Sinsemilla hash evaluations from the initial point hcommon​ with the message suffixZSA​ and suffixZEC​ respectively {hZEC​=SinsemillaHash(hcommon​,suffixZEC​)hZSA​=SinsemillaHash(hcommon​,suffixZSA​)​
  4. Select the desired hash thanks to a multiplexer gate h=MUX(hZSA​,hZEC​,AssetBase==VOrchard)
